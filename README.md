# 핑구섬 경제 노트 · 내 휴대폰 앱으로 만들기

이 폴더를 인터넷에 올리면 **휴대폰 홈 화면에 앱처럼 설치**할 수 있고, 한 번 연 뒤에는 **인터넷 없이도** 공부할 수 있어요.
claude.ai 게시 페이지에서는 설치와 오프라인 실행이 되지 않아서, 내 주소가 하나 필요해요. GitHub Pages를 쓰면 무료예요.

## 폴더에 든 것

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 본체 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 색 같은 설치 정보 |
| `sw.js` | 인터넷 없이도 열리게 해 주는 오프라인 저장 파일 |
| `icons/` | 홈 화면 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리게 하는 빈 파일 |

## 1. GitHub Pages에 올리기 (컴퓨터 권장, 한 번만)

1. [github.com](https://github.com)에서 계정을 만들고 로그인해요.
2. 오른쪽 위 **+** → **New repository**를 눌러요.
   - Repository name: `pinggu` (원하는 영어 이름)
   - **Public**을 고르고 **Create repository**를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 폴더 **안의 파일과 icons 폴더를 모두** 끌어다 놓아요. (폴더째가 아니라 안의 내용물을 올려요.)
   - `.nojekyll`처럼 점으로 시작하는 파일이 안 보이면 없어도 괜찮아요.
5. 아래 **Commit changes**를 눌러요.
6. 저장소의 **Settings** → 왼쪽 **Pages**로 가요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
7. 1~2분 뒤 새로 고침하면 위쪽에 주소가 나와요.
   `https://내아이디.github.io/pinggu/`

## 2. 휴대폰에 설치하기

- **안드로이드(크롬)**: 주소를 열고 → 오른쪽 위 ⋮ → **앱 설치**(또는 홈 화면에 추가). 게임 설정의 **앱으로 설치 → 설치** 버튼으로도 돼요.
- **아이폰(사파리)**: 주소를 사파리로 열고 → 아래쪽 공유 버튼(□↑) → **홈 화면에 추가**.

설치한 뒤 **인터넷이 될 때 한 번 끝까지 열어 두면** 그다음부터는 비행기 모드에서도 열려요.
처음 설치할 때 글꼴도 함께 저장해요. 혹시 오프라인에서 글씨체가 달라 보이면, 인터넷이 될 때 한 번 더 열어 주세요.

## 3. 그동안의 기록 옮기기

주소가 바뀌면 기록이 따로 저장돼요. 저장 코드로 옮겨요.

1. 원래 하던 곳(claude.ai 게시 페이지)에서 오른쪽 위 **톱니바퀴** → **저장 코드 → 내보내기** → **복사하기**
2. 새로 설치한 앱에서 **톱니바퀴** → **저장 코드 → 불러오기** → 붙여 넣고 **불러오기**

## 4. 새 버전으로 바꾸기

새 압축 파일을 받으면 저장소에서 **Add file → Upload files**로 같은 이름의 파일을 다시 올리고 Commit 해요.
앱은 인터넷이 될 때 열면 새 버전을 알아서 받아요. (기록은 그대로 남아요.)

## 5. 잘 안 될 때

- **주소가 404예요**: Pages를 켠 뒤 1~2분 기다리고, `index.html`이 저장소 맨 위(폴더 안이 아닌 곳)에 있는지 확인해요.
- **설치 메뉴가 안 보여요**: 주소가 `https://`로 시작하는지 확인하고, 한 번 새로 고침한 뒤 다시 메뉴를 열어요. 아이폰은 꼭 **사파리**로 열어야 해요.
- **오프라인에서 안 열려요**: 인터넷이 될 때 앱을 한 번 끝까지 연 다음 다시 해 봐요.
